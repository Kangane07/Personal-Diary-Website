# 📝 Personal Diary Website

A simple multi-user personal diary web app where users can write, save, and manage their daily thoughts directly in the browser.

---

## 🚀 Features

* 👤 Create multiple users
* ✍️ Write diary entries
* 📂 Save entries as **Draft** or **Final**
* 🔍 Search entries easily
* 📊 View stats (entries count, words, etc.)
* 🌙 Dark / Light mode
* 📤 Export data as JSON
* 🗑️ Delete entries or users

---

## 🛠️ Tech Stack

* HTML
* Tailwind CSS
* JavaScript (Vanilla)
* LocalStorage

---

## ⚙️ How It Works

* Data is stored in your browser using **LocalStorage**
* No backend or database needed
* Works offline after loading

---

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/personal-diary-website.git
   ```

2. Open the project:

   * Open `index.html` in your browser
